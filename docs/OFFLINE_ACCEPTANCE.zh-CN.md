# MatchLens 当前实现与离线验收

更新：2026-10-27。本轮未调用任何模型 API，没有训练或微调。当前可演示的是接入真实本地事件流的离线事实模式；真实模型运行仍须用户再次授权。

## 功能对照

| 要求 | 本轮实现 | 实际边界 |
| --- | --- | --- |
| 接入事件 | 按到达时间逐条接入、去重、冲突检查、事件时间及到达时间双重隔离、SSE 更新 | 来源是本地合成数据回放，不是官方实时数据源 |
| 解读事件 | 比分、球权、传球成功率、传球距离/难度、夺回球权至射门、压迫变化、比赛节奏 | 难度与节奏为公开规则，不是训练后的概率模型 |
| 解释时刻 | 从事件关系解释夺回后射门、持续压迫、球权频繁变化、换人及阵型前后对比；每条故事有窗口与证据 | 当前自然语言来自明确标示的离线规则；不把时间先后说成已证明因果 |
| 呈现洞察 | 当前球员/球位置、压迫地块、已发生的传球路线、换人、进球反应；支持带时间/有效期/证据的 JSON 导出 | 无主办方转播叠加系统接入；旧 24 秒脚本文案不再驱动页面 |
| 个性化 | Fan/Analyst、球迷/教练/解说员、关注球队、持续关注球员、指标与中英文；保留可拖动模块布局 | 语言与身份变化已离线测试，模型个性化质量待授权后验证 |
| 球员与速度 | 姓名/号码标记、专属高亮、可观测移动距离、7 m/s 阈值、采样球速、完成射门飞行的平均速度 | 身份来自数据；2 Hz 不支持瞬时峰值，缺失段不补造速度或距离 |
| 自动事件提取 | 实际视频像素 → 色彩分类/最大连通区域 → 时序持球模型 → 传球/拦截/球权变化/射门估计、速度与 JSONL 导出 | 仅固定俯视、已标定、颜色编码的合成视频；真实转播识别及预训练视觉模型尚未接入 |
| 叙事与回顾 | 当前范围回顾、终场后全场回顾、首次射门、进球、传球里程碑、换人、夺回后射门的关键片段 | 统计与回顾仅覆盖可见记录；本轮没有重新验证生成式 Recap Agent |
| 数据创新 | 三份配对反事实/缺失数据案例；另有可复现 90 分钟完整模拟、半场换边、动态上场名单 | 足球动作结构一致，不声称已拟合职业比赛统计分布 |
| 多 Agent | 现有 6 角色 Harness、工具/共享事实、独立审核及一次修订；接入持续调度与前端 | 用户授权门关闭，因此不能把本轮离线演示描述成真实多 Agent 调用 |

## 运行与演示

```bash
python3 -m backend.server --port 43128
```

- 页面：<http://127.0.0.1:43128/>
- 视频实验室：<http://127.0.0.1:43128/video-lab.html>
- `01` 在 68 秒展示夺回球权至射门的 7 秒序列；`02` 同一时刻不宣称 Atlas 完成这一序列。
- `03` 在 58 秒缺少位置及压迫数据：球员/球不补画，当前球速显示未知；仍可观察到的事件保留。
- `90′` 的 seed 83 包含 13,553 条记录、2,738 条事件、25 次射门（上半场 13、下半场 12），终场 Atlas 0–1 Union；时间线支持毫秒级终场到达时刻。
- 切换 Fan/Analyst 不改变时间线；Your view 改变叙事与统计关注对象。回顾可导出 JSON；叠加层导出保留窗口、到期时间与证据。

## 已完成的验收

1. **53 项 Python 检查通过**：原有数据/Harness/适配器测试，以及到达隔离、重复/迟到/未来事件、回退、旧结果失效、偏好变化、完整比赛、度量、SQLite、HTTP/SSE、回顾与授权门测试。
2. **12 项 JavaScript 检查通过**：原有渲染几何、名单与动作检查，以及新流适配、缺失画面、过期消息、像素身份、自动传球/拦截、缺失中断和射门估计。
3. **四份数据全部通过结构/几何校验**：两个 schema、动态 22 人名单、替补、半场不连续、位置、速度、球权及到达时间；原有三份数据保持不变。
4. **浏览器实际操作**：Fan/Analyst、回放跳转、英文球员关注、事件引用打开原始 JSON、缺失数据场景、回顾面板。
5. **实际视频实验**：浏览器录制并解码约 12 秒视频，从 283 帧识别 22 个身份色，提取 4 次传球、2 次拦截及对应的夺回/球权变化、1 次射门及结束，共 12 条估计事件。第一次实现曾把经过球员附近的球误判为接球；通过低速稳定接球条件与最大连通区域过滤后重新录制并验证。该结果只是受控样例验证，不是转播识别准确率。

实际视频和提取结果保存在 `run-output/video-lab/calibrated-demo.webm`、`run-output/video-lab/observed-events.jsonl`。运行故事保存在 `run-output/stories.sqlite3`，不上传到外部服务。

## API 状态与下一步

`config/model-policy.json` 的 `enabled=false`、请求预算 0。旧密钥已从 `.env.local` 移除，其指纹被拒绝复用；策略缺失或无效也拒绝调用。DeepSeek 与 Ollama 在每次实际请求前都检查授权。浏览器没有解除这一限制的入口。

模型调用必须等用户再次明确授权，并使用不同凭证。授权后应先做有预算的小规模验收：真假压迫分支、缺失数据、中英文与球员偏好、模型审核退回、连续播放延迟和过期结果。历史 DeepSeek 文案曾出现过度概括，不能因本轮代码测试通过就认定模型质量问题已经解决。

Microsoft Foundry、Microsoft Agent Framework、Azure 与官方数据源仍未接入。真实转播的通用视频识别未完成。两分钟正式作品、公开部署和提交也未在本轮执行；当前提交草稿已移除与实际实现不符的技术和 xG 宣称。
