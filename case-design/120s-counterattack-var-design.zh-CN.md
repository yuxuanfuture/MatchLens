# 120 秒攻防与越位复核案例设计

确认日期：2026 年 10 月 27 日。

比赛进入下半场伤停补时，双方仍为 0–0，第四官员宣布至少补时 2 分钟。A 队压上争取领先，持续组织进攻并进入禁区，B4 在禁区内完成合法铲断。B 队通过三次传球形成单刀，B9 过掉门将后射门入网。助理裁判随后举旗，主裁初判越位、进球无效；经 VAR 检查与场边复核，主裁撤销初判，最终确认进球有效，B 队在补时取得领先。

本例确定 120 秒的故事、关键位置及判罚时间线，作为后续生成事件和全员轨迹的依据。JSONL 与轨迹数据尚未生成。

## 比赛设定

| 项目 | 设定 |
| --- | --- |
| 片段长度 | 120 秒，包含 0 秒与 120 秒的位置采样 |
| 比赛时钟 | 下半场伤停补时 90:00 至 92:00 |
| 宣布的最低补时 | 2 分钟，VAR 审查与庆祝造成的延误继续计入补时 |
| 初始比分 | A 0–0 B |
| 片段末正式比分 | A 0–1 B |
| 片段末比赛状态 | 尚未终场，A 队准备重新开球 |
| 人数 | A、B 两队各 11 人，全程无人被罚下或换人 |
| 球场 | 105 × 68 米，坐标单位为米 |
| A 队攻向 | x 增大，进攻目标在 x=105 的球门 |
| B 队攻向 | x 减小，进攻目标在 x=0 的球门 |
| 初始控球队伍 | A 队 |
| 数据覆盖 | 全程提供事件、事件位置、全员追踪与压迫信息 |

表中时间均为片段内的事件发生时间。沿用原案例的 80 毫秒到达延迟时，接收端会稍晚获知；例如第 115 秒的最终判罚在第 115.08 秒到达。

## 补时背景与比赛时钟

片段从 90:00 开始，内部事件时间仍从 0 毫秒计起。沿用现有时钟字段时，`period=2`，`match_clock_start_ms=5400000`；比赛时钟由该起点加上片段内发生时间得到。

| 片段时间 | 比赛时钟 | 关键事件 |
| --- | --- | --- |
| 0 秒 | 90:00 | 双方 0–0，A 队组织进攻 |
| 72 秒 | 91:12 | B4 在禁区内完成合法铲断 |
| 83 秒 | 91:23 | B10 送出第三脚直塞，B9 随后突破防线 |
| 90 秒 | 91:30 | B9 射门入网，有效性待判定 |
| 92 秒 | 91:32 | 主裁初判越位，进球无效 |
| 115 秒 | 91:55 | 主裁撤销初判，确认进球有效，比分变为 0–1 |
| 120 秒 | 92:00 | B 队庆祝，A 队准备重新开球，片段结束 |

补时牌显示的是最低补时时间，VAR 审查和进球庆祝造成的延误仍须补回。因此 92:00 仅为本例片段结束，后续比赛留在片段之外，不在此时生成终场哨或终场事件。本例可以表述为“补时取得领先”或“可能的制胜进球”，不能在尚未终场时断言为绝杀。

## 主要参与者

| 球员 | 本例角色 |
| --- | --- |
| A1 | A 队门将，反击中出击，被 B9 过掉 |
| A4、A5 | A 队中卫，反击中回追；第三脚传球时提供越位线的位置依据 |
| A6、A8、A10 | A 队组织、推进与禁区前接应 |
| A7 | A 队侧翼推进与禁区内倒三角传球 |
| A9 | A 队禁区内接球者，准备射门时被 B4 铲断 |
| B1 | B 队门将，参与防守站位，本例没有完成扑救 |
| B2、B3、B5、B6 | B 队压迫、限制传球路线与保护禁区 |
| B4 | B 队中卫，合法铲断后控制球，并传出反击第一脚 |
| B10 | B 队反击连接点，送出第三脚直塞 |
| B9 | B 队反击前锋，合法启动、单刀过门将并完成射门 |

完整名单保留两队各 11 人。未直接参与持球动作的球员仍需持续跑位、回收或提供接应，不能只移动事件中的球员。

## A 队组织与第一次推进

| 时间 | 比赛过程 | 关键位置与结果 |
| --- | --- | --- |
| 0–5 秒 | A4 带球后传给 A6 | A4 从 (30,24) 带至 (36,24)，A6 在 (45,33) 接球 |
| 5–11 秒 | A6 带球后传给 A8 | A6 带至 (51,33)，A8 在 (59,44) 接球 |
| 11–17 秒 | A8 带球后传给 A7 | A8 带至 (65,46)，A7 在 (72,54) 接球，首次进入进攻三区 |
| 17–22 秒 | A7 沿侧翼推进，A9 向禁区方向跑动 | A7 带至 (80,53) |
| 22–24 秒 | B3 靠近 A7，限制继续向前的路线 | A7 保持控球；记录 B3 的压迫及双方位置 |
| 24–30 秒 | A7 回传 A8，A8 向内调整 | A8 在 (75,44) 接球，再带至 (78,39) |

这一段的传球顺序为 A4 → A6 → A8 → A7 → A8。

## A 队重新组织与 B 队防守

| 时间 | 比赛过程 | 关键位置与结果 |
| --- | --- | --- |
| 30–35 秒 | A8 传给 A10，A10 向前带球 | A10 在 (85,28) 接球，带至 (88,26) |
| 35–37 秒 | B6 压迫 A10，限制其转身与向前传球 | A10 没有丢球 |
| 37–43 秒 | A10 回传 A6，A6 调整后传给 A4 | A6 在 (80,34) 接球，调整至 (78,31)，A4 在 (65,25) 接球 |
| 43–48 秒 | A4 带球后再次向前传给 A8 | A4 带至 (68,27)，A8 在 (80,44) 接球 |
| 48–52 秒 | A8 再次沿侧方推进 | A8 带至 (86,46) |
| 52–54 秒 | B2 上前限制 A8，B4 在禁区内保护 A9 身前区域 | B 队形成外侧施压、内侧保护的防守分工 |

各次压迫需要由追踪位置支持。压迫期间的持球与护球动作应连续，不能通过暂停所有球员来填充时间。

## A 队攻入禁区与 B4 铲断

| 时间 | 比赛过程 | 关键位置与结果 |
| --- | --- | --- |
| 54–56 秒 | A8 传给禁区前沿的 A10 | A10 在 (87,34) 接球 |
| 56–60 秒 | A10 带球进入 B 队大禁区 | A10 带至 (90,32) |
| 60–62 秒 | B5 靠近 A10，限制射门角度；A7 插入侧方接应 | A10 仍控制球 |
| 62–64 秒 | A10 传给禁区侧方的 A7 | A7 在 (92,44) 接球 |
| 64–68 秒 | A7 带球后倒三角传给 A9 | A7 带至 (94,42)，A9 在 (93,31) 接球 |
| 68–71 秒 | A9 控球调整，准备射门；B4 从侧面接近 | A9 调整至 (94,31) |
| 71–72 秒 | B4 完成合法的侧面滑铲，终止 A9 的射门机会 | 铲球接触点约为 (94,31)，球被铲至附近 (93,32)；无犯规，裁判允许继续 |
| 72–72.5 秒 | 球短暂成为松散球，随后 B4 获得控制 | B4 在 (93,32) 控球，球权转为 B 队 |

本轮 A 队没有完成射门。A9 被铲断前的射门准备不计入射门数。

“干净铲断”需同时具备动作方式、触球情况、无犯规判定和后续球权依据。仅记录抢断成功或先碰到球，不能单独证明动作合法。

铲球、获得松散球与球权更新描述同一次转换，应互相关联，统计时只计算一次成功夺回。

## B 队三次传球与单刀

反击传球顺序为 B4 → B6 → B10 → B9，共三次成功传球。

| 时间 | 比赛过程 | 关键位置与结果 |
| --- | --- | --- |
| 72.5–74 秒 | B4 起身并带球调整 | 从 (93,32) 至 (90,32) |
| 74–75.5 秒 | 第一传 B4 → B6 | B6 在 (72,38) 接球，球离开本方禁区附近 |
| 75.5–78 秒 | B6 接球转身并推进 | 带至 (63,36) |
| 78–80 秒 | 第二传 B6 → B10 | B10 在 (48,29) 接球，反击越过中线 |
| 80–83 秒 | B10 带球，B9 准备向身后启动 | B10 带至 (40,31)，A 队两名中卫被拉开 |
| 83–85.5 秒 | 第三传 B10 → B9 | B10 出球后 B9 越过防线，在 (25,34) 接球，形成单刀 |
| 85.5–87.5 秒 | B9 加速进入 A 队禁区，A1 出击 | B9 带至 (13,34)；A4、A5 在身后回追 |
| 87.5–88.5 秒 | B9 假动作后拨球绕过 A1 | B9 控制球至约 (9.5,39)，A1 扑球未触球 |
| 88.5–89.5 秒 | B9 跟进并调整射门 | 带至 (7,38)；回追后卫未能在射门前完成封堵 |
| 89.5 秒 | B9 起脚射门 | 射门指向 x=0 一侧球门中央，门线交点约为 (0,34) |
| 90 秒 | 球完整越过门线 | 记录入网事实，进球有效性待判定，正式比分仍为 0–0 |

门将扑球未触球不记为成功扑救。过门将属于 B9 持续控球过程，应保留对手 A1、动作方式与过人结果。

追踪数据应支持单刀成立：B9 合法启动后跑到防线身后，A1 成为其与球门之间的主要直接防守者；A4、A5 的回追位置和速度不能使其实际上先于 B9 到达射门点。

## 越位争议与最终进球

| 时间 | 裁判与比赛过程 | 正式比分与当前结论 |
| --- | --- | --- |
| 90 秒 | 球入网，B 队开始庆祝 | 0–0，入网有效性待判定 |
| 90.5 秒 | 助理裁判举旗，报告 B9 疑似越位 | 0–0，记录助理裁判的判断 |
| 92 秒 | 主裁接受越位意见，作出进球无效的初始判罚；VAR 开始核查 | 0–0，当前有效判罚为越位无效，审查中 |
| 92–99 秒 | VAR 定位 B10 出球的准确瞬间，核对 B9 和倒数第二名防守球员的位置 | 0–0，尚无主裁最终改判 |
| 99–104 秒 | VAR 向主裁提供回放信息，主裁示意复核并前往场边屏幕 | 0–0，比赛保持停止 |
| 104–114 秒 | 主裁查看出球瞬间与连续回放，核实 B9 出球时处于合法位置、随后才越过防线 | 0–0，仍待最终决定 |
| 114–115 秒 | 主裁结束场边复核并准备传达判罚 | 0–0，尚未公布最终决定 |
| 115 秒 | 主裁做出电视手势，撤销越位初判并指向中圈，确认进球有效 | A 0–1 B |
| 115–120 秒 | B 队再次庆祝，A 队准备重新开球 | A 0–1 B，尚未重新开始比赛 |

助理裁判采用延迟举旗：进攻完成前，主裁没有鸣哨中断这次进攻。初判、复核与最终改判均保留，最终决定替代初判的当前效力，不删除历史记录。

纯位置越位通常由 VAR 核实后直接告知主裁。本例处于补时关键进球的判罚阶段，为管理比赛与清楚传达关键判罚，采用规则允许的场边复核路径。

## 出球瞬间的越位证据

本例的争议针对第 83 秒 B10 的第三脚传球。第 90.5 秒举旗是助理裁判报告该判断的时刻，不能把举旗时间当作越位位置的判断时刻。

| 证据 | 设定 |
| --- | --- |
| B10 首次触球出球时刻 | 83,000 毫秒 |
| B 队攻向 | x 减小 |
| 出球时球的位置 | 约 (40,31) |
| B9 最靠近对方球门的可判越位身体部位 | x=33.6 |
| A 队倒数第二名防守球员相应部位 | x=33.0 |
| 出球瞬间的关系 | B9 距离对方球门远 0.6 米，处于合法位置 |
| 后续动作 | B9 随后才越过防线并接球 |
| 助理裁判报告 | 认为 B9 启动过早，提出越位判断 |
| 最终判罚 | 回放证据支持合法启动，撤销越位初判，进球有效 |

33.6 与 33.0 表示可判越位身体部位的位置，不直接等同于球员中心坐标。越位证据应保存出球瞬间、球的位置及相关身体部位快照，普通全员位置采样承担连续跑位展示。

第 99 秒出现的 VAR 证据关联第 83 秒的出球事实，但其审查信息到达时间仍属于第 99 秒。不得把最终判罚、复核结论或“合法启动”标签提前写入初始背景与早期事件。

## 球权与比分状态

### 球权

| 时间 | 比赛状态 |
| --- | --- |
| 0–72 秒 | A 队控制球，B 队进行防守 |
| 72–72.5 秒 | 铲球后短暂松散球，无球队确认控制 |
| 72.5–89.5 秒 | B 队控制进攻；传球在途时不强行指定持球人 |
| 89.5–90 秒 | 射门飞行中，无球员持球 |
| 90–120 秒 | 死球，等待判罚、复核及重新开球 |

庆祝、VAR 审查与准备重新开球的时间不计入 B 队的比赛控球时间。死球期间 22 名球员仍有回位、庆祝等位置变化。

### 比分

| 时刻 | 已知事实与判罚 | 正式比分 |
| --- | --- | --- |
| 入网前 | 尚无进球候选 | A 0–0 B |
| 90 秒入网后 | 球已入网，待判定有效性 | A 0–0 B |
| 92 秒初判后 | 当前判罚为越位、进球无效 | A 0–0 B |
| 复核期间 | 保留当前判罚，等待主裁最终决定 | A 0–0 B |
| 115 秒最终决定后 | 越位初判被撤销，确认同一次入网有效 | A 0–1 B |

进球的足球发生时间仍是第 90 秒，第 115 秒是确认其有效的判罚时间。数据必须同时表达发生时间与获知时间；例如确认后的进球记录可保留 `event_time_ms=90000`、`observed_at_ms=115080`，并关联第 115 秒的最终判罚。该确认只计一次有效进球。

## 沿用的数据层级

| 记录类别 | 本例要求 |
| --- | --- |
| metadata | 1 条，提供中性比赛背景、两队名单、攻向、初始比分与时钟起点 |
| event | 传球、带球、压迫、铲球、夺回、球权转换、射门、入网结果，以及裁判和 VAR 事实 |
| tracking | 241 帧，0–120 秒每 500 毫秒采样一次，包含全部 22 名球员和球的位置 |
| coverage | 初始声明各通道可用，全程不安排缺口，无需额外覆盖状态变更 |

与旧案例一致，带球和传球记录动作起止时间，完成结果在可知后提供；射门在起脚时不带未来结果。所有推理输入同时受事件时间和到达时间限制。

裁判、VAR 记录及关联字段需要在后续数据实现中支持，现有输入校验器尚未支持全部这类事件。叙事统一称 A、B 队；当前读取器的第二队内部编码为 U，落地时需统一映射或明确扩展，不能混用 B 与 U。

预期答案、场景名称中的结局提示和本设计说明与运行输入分开保存。

## 后续数据验收条件

- A 队的推进、受压、回传、入禁区与 B 队防守位置相互一致。
- B4 的铲球合法、有明确对手与结果，后续控球依据完整；夺回不重复计数。
- B 队反击的三次传球依次为 B4→B6、B6→B10、B10→B9，均有合理接球与连续球轨迹。
- 出球瞬间的越位证据支持 B9 合法启动，助理裁判的报告与最终事实分别编码。
- 单刀、门将出击、过门将和射门均由全员及球的位置支持，不能通过瞬移或冻结回追者形成。
- 第 90 秒记录入网；初判后与复核期间保持 0–0；仅在最终判罚到达后变为 0–1。
- 回放到最终判罚之前时，不显示已确认进球，也不泄露第 115 秒的裁判决定。
- 第 120 秒对应比赛 92:00，比分 0–1，尚未重新开球；最低补时 2 分钟不能自动触发比赛终场。
- VAR 审查及庆祝造成的延误仍须补回；本例只结束片段，不生成终场事件，也不提前认定绝杀或最终胜负。

## 规则依据

- [IFAB 场地规则](https://www.theifab.com/laws/latest/the-field-of-play/)：禁区范围。
- [IFAB 比赛时间规则](https://www.theifab.com/laws/latest/the-duration-of-the-match/)：最低补时时间与 VAR 审查、进球庆祝造成延误的补偿。
- [IFAB 犯规规则](https://www.theifab.com/laws/latest/fouls-and-misconduct/)：合法争抢与犯规的区分。
- [IFAB 越位规则](https://www.theifab.com/laws/latest/offside/)：出球瞬间与可判越位身体部位。
- [IFAB VAR 协议](https://www.theifab.com/laws/latest/video-assistant-referee-var-protocol/)：延迟举旗、初始决定、复核及主裁最终决定。
